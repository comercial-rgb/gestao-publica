## O que fica

- A prestação de contas do projeto de 2026 (SAGRES §4.41 a §4.45) não tem como sair: a tela da LOA diz isso, e nenhuma
  versão é fabricada.
- Para o projeto de 2027 em diante, o sistema guarda a versão no dia do encaminhamento: o encaminhado, a mensagem
  modificativa e o emendado na Câmara, cada um como cópia imutável (Planejamento › Leis orçamentárias › a lei).
- Depois da lei aprovada, a mesma tela mostra o que mudou de cada versão para a lei (dotação e receita, linha a linha),
  sem alterar a cópia.
- Pedido objetivo ao município, se o original existir: o PDF do projeto e a mensagem com a data de protocolo na
  Câmara. Ele seria guardado aqui como documento. Ainda assim não vira versão do projeto retroativa, porque o
  planejamento daquele dia não está no sistema.
