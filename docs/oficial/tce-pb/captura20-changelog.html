Changelog - v0.5.0 - (08/04/2026)

Alterações

Foi realizada a padronização da propriedade utilizada para o envio da lista de elementos no JSON Schema das entidades Ação, Programa, Unidade Orçamentária, Receita Prevista e Dotação.

As propriedades anteriormente utilizadas (acoes, programas, unidadesOrcamentarias, receitasPrevistas, dotacoes) foram substituídas por uma única propriedade padrão: elementos, adotada em todas as entidades.

Além disso, na entidade Receita Prevista, o campo tipoReceita foi renomeado para tipoReceitaLancada

Removido

A propriedade exercicio foi removida dos elementos das entidades do Orçamento, deixando de fazer parte da estrutura do elemento
